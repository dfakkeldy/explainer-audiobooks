# The Message

*Conversations, Content Blocks, and the Messages API*

By Dan Fakkeldy. Written and produced with OpenAI Codex (GPT-5), using the
official Claude Platform documentation as the primary source.

![Cover for The Message](cover.png)

This is Volume 1 of the Claude Platform Documentation audiobook series. It is
a beginner, mechanism-first road book about the direct Messages API: the API
boundary, structured messages and content blocks, conversation history,
request controls, response evidence, and the application decisions around a
model call.
