# You Are the Architect (Second Edition)
_From vibe coding to agentic engineering — the new SDLC, and what to do differently_

![Cover](cover.png)

> Generation is solved. Verification, judgment, and direction are the new craft.

This is a narrated, beginner-friendly audiobook about building real software with an AI coding agent — rebuilt from the ground up around Google's May 2026 whitepaper **"The New SDLC with Vibe Coding: From ad-hoc prompting to Agentic Engineering"** (Addy Osmani, Shubham Saboo, Sokratis Kartakis), with Osmani's O'Reilly book *Beyond Vibe Coding* as a supporting reference. Where the first edition toured the tool, this edition teaches the framework — and lands every chapter on **what you should do differently and how to get better results**.

Everything is still grounded in one true, shipping, open-source app: **Echo**, an audiobook study player built by a solo developer — a mail carrier on a modest sixteen-gigabyte Mac — by directing Claude Code rather than typing the code himself. And unlike the first edition, this one **names the real things out loud** — CLAUDE.md, xcodebuild, TestFlight, MCP, hooks and skills by their actual names — so you finish knowing the vocabulary, not a fog.

## What you'll learn

- **The spectrum** from vibe coding to agentic engineering — six dimensions, and how to place every task deliberately by its stakes
- **Proof as the differentiator** — tests for the deterministic parts, evals for the fuzzy parts, and why "it seems to work" is not verification
- **Context engineering** — the six types of context, static vs dynamic, and Agent Skills
- **The new SDLC** — what AI actually changes phase by phase, and why specification quality is the new bottleneck
- **The factory model and the harness** — why your real product is the system that produces the code, and why most agent failures are configuration failures
- **Conductor vs orchestrator, the 80% problem, the token economy** — and a concrete Monday playbook of the paper's six practices

## Who it's for

Anyone who already uses (or is about to use) an AI coding agent and wants better results — from the curious near-beginner to the experienced developer deciding how much structure each task deserves.
