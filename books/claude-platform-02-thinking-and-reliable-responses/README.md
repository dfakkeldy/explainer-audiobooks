# Making Claude Think and Respond Reliably

*Reasoning, Multimodal Inputs, Structured Output, and Streaming*

By Dan Fakkeldy. Written and produced with OpenAI Codex (GPT-5), using the
official Claude Platform documentation as the primary source.

![Cover for Making Claude Think and Respond Reliably](cover.png)

This is Volume 2 of the Claude Platform Documentation audiobook series. It is
a beginner, mechanism-first road book about request-time capability choices:
extended and adaptive thinking, effort and token budgets, structured outputs,
images and documents, citations, streaming events, batch processing, and the
application decisions that make responses reliable.
