# Giving Claude Tools

*Contracts, Agent Loops, and Controlled Action*

By Dan Fakkeldy. Written and produced with OpenAI Codex, using the official
Claude Platform documentation as the primary source.

![Cover for Giving Claude Tools](cover.png)

This is Volume 3 of the Claude Platform Documentation audiobook series. It is
a mechanism-first road book about client-defined tools and the application-owned
agent loop: contracts, tool requests and results, validation, authorization,
approval, parallel execution, strict tool use, tool choice, the SDK Tool Runner,
caching, and controlled side effects. Managed tools remain the subject of
Volume 4.
