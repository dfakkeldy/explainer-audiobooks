# J-Space: Inside the Machine

*Parameters, Working Memory, and the Question of Consciousness*

By Dan Fakkeldy, with Codex as contributor.

![Cover for J-Space: Inside the Machine](cover.png)

This is a long, gentle road book about the machinery needed to understand
J-Space. It starts with parameters, context, and the changing activity of a
model during inference; builds a careful comparison with human working memory;
and then separates access-like evidence from the harder question of phenomenal
consciousness. *Severance* appears as a bounded analogy for discontinuity,
labor, and moral uncertainty, not as evidence about model architecture.
