# Documentation

This directory contains current public guides, active development material,
dated operational evidence, and historical design records. They have different
roles: use the current guides to run the workflow, and use dated records to
understand or reproduce a particular past edition.

## Current guides

- [How these were made](how-these-were-made.md) explains the current grounded,
  single-author, spoken-first production method.
- [Make your own](make-your-own.md) covers setup, skill routing, private book
  production, and the separate public-promotion lane.
- [Publishing a public edition](../skill/references/publishing-a-public-edition.md)
  is the governed runbook for promoting an explicitly authorized private book.

The executable contracts live with the skills themselves:

- [Direct nonfiction audiobook production](../skill/SKILL.md)
- [Longform nonfiction development](../skills/longform-book-development/SKILL.md)
- [Fiction manuscript development](../skills/fiction-book-development/SKILL.md)
- [Fiction audiobook production](../skills/fiction-audiobook/SKILL.md)

## Current development packets

- [Nova Scotia tax-sale book packet](nova-scotia-tax-sale-book/) contains the
  public-safe research, manuscript history, maps, figures, and receipts behind
  the governed-final *Beyond the Tax-Sale Packet*. Its README states current
  publication status; files explicitly marked historical preserve earlier
  production gates.

Public book packages belong under [`books/`](../books/). A public-safe draft is
not necessarily publication-ready; each package or development README states
its own review and delivery boundary.

## Dated operational evidence

These folders preserve review material for specific past operations:

- [`audio-recovery-2026-07/`](audio-recovery-2026-07/)
- [`cover-pilots/`](cover-pilots/)
- [`cover-refresh-2026-07/`](cover-refresh-2026-07/)

Their manifests, contact sheets, and receipts are evidence for those dated
operations. They are not current installation or production instructions.

## Historical plans and specifications

[`superpowers/`](superpowers/) contains dated design specifications and
implementation plans. They explain why a change was proposed and how it was
implemented at that time. Later skill contracts, current guides, and final
publication receipts supersede them whenever behavior or status changed.

Historical files remain in place so links, approvals, and artifact provenance
stay reviewable. When one is superseded, prefer a clear archival banner over
rewriting the original evidence.
