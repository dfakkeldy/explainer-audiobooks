## Wrong or unclear in the original (flagged, not silently fixed)

1. **"title request" (Alder Crossing).** The original says the unreconciled file "cannot support a title request". Its next authority is already "the governed land-record review interpreted by counsel", so this reads as a contradiction. It probably means a title opinion on one defined parcel, or a request that assumes a single parcel. I kept "the title request … waits". Dan should say what was meant.
2. **Union Workshop's intro calls it "an occupied building"**, but the evidence paragraph only says an exterior view "suggests that the premises are occupied". I wrote "a building that appears occupied" in the intro to match the evidence.
3. **The "past event" in the historical paragraph is unnamed.** I matched it to Inverness May 2025 (DATA-003). If another Inverness event was meant, the date and source line need changing.
4. **`fig-research-file` draw note says "fictional Case C".** The textbook edition never names its composite cases with letters, so a reader would meet "Case C" cold. It could also collide with Chapter 6's `fig-access-plan`, which uses Parcels A–E as diagram labels. Case C was the original's label for Meadow Line (figures 33–37, "Parcel C"). Recommend the infographic say **Meadow Line** and match the case box: identity matches; road frontage → lawyer; boundary → surveyor; condition → inspection; planning questions to municipal staff; environmental, well, sewage, coastal and mine searches with no mapped intersection. The draw note's "water" context has no Meadow Line result in the text; if the figure shows it, show it as a searched layer with no intersection.
5. **`fig-four-buckets` and `fig-research-file`** both cite only MAP-001. They are method figures, so this is harmless, but the research-file figure could also cite DATA-002 (summary/detail reconciliation) and LAND-001 (AAN/PID jobs).
